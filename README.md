# OrderSaga - Система управления заказами с паттерном Saga

## Описание

Проект демонстрирует реализацию распределённых транзакций и управления заказами в микросервисной архитектуре. Вместо реальных микросервисов используется абстракция: каждый микросервис представлен классом, а ручки микросервиса - методами класса.

Согласованность данных обеспечивается через **паттерн Saga (оркестратор)** с компенсационными транзакциями при сбоях.

## Особенности реализации

### Точность финансовых операций

Все денежные суммы хранятся в **копейках** (`int64_t`) через класс `Money`, что исключает ошибки округления при операциях с деньгами:

```cpp
// Создание денежных сумм
Money price = Money::FromRubles(1000);                    // 1000 руб.
Money exact = Money::FromRublesAndKopecks(99, 99);        // 99.99 руб.

// Операции
Money total = price * 3;                                  // 3000 руб.
Money discounted = total.ApplyDiscount(10.0);             // -10% = 2700 руб.

// Получение значений
int64_t kopecks = price.GetKopecks();  // 100000 копеек
std::string str = price.ToString();    // "1000.00"
```

## Сервисы

### 1. DiscountService (Сервис скидок)
- Персональные скидки пользователей
- VIP-статус (+5% к скидке)
- Бонус за количество заказов (+2% за каждые 10 заказов)
- Бонус за большой заказ (+3% при сумме ≥ 10000 руб.)
- Максимальная скидка ограничена 30%

### 2. BillingService (Сервис оплаты)
- Управление балансами пользователей
- Обработка и подтверждение платежей
- Возврат средств (компенсация)
- Пополнение баланса

### 3. InventoryService (Сервис склада)
- Управление товарами
- Резервирование и подтверждение резервов
- Освобождение резервов (компенсация)

### 4. NotificationService (Сервис уведомлений)
- Симуляция отправки уведомлений о статусах заказов
- Логирование операций

### 5. OrderService (Сервис заказов)
- Создание и обработка заказов
- Отмена заказов с компенсацией
- Интеграция с Saga оркестратором

## Паттерн Saga

### Шаги успешного выполнения заказа:
1. **Уведомление о создании** → NotificationService
2. **Резервирование товаров** → InventoryService
3. **Применение скидки** → DiscountService
4. **Обработка платежа** → BillingService
5. **Подтверждение платежа** → BillingService
6. **Подтверждение резервирований** → InventoryService
7. **Обновление статистики заказов** → DiscountService
8. **Уведомление об успехе** → NotificationService

### Компенсационные действия при сбое:
- Возврат средств на баланс
- Освобождение зарезервированных товаров
- Отмена применённой скидки
- Уменьшение счётчика заказов
- Уведомление о сбое

## Сборка и запуск

### Требования
- CMake 3.14+
- C++17 совместимый компилятор

### Сборка
```bash
mkdir build && cd build
cmake ..
make
```

### Запуск
```bash
# Консольное приложение
./order_saga

# Все тесты
./tests

# Запуск конкретного теста (по имени или части имени)
./tests Saga_SuccessfulOrder      # Запустит тест Saga_SuccessfulOrder
./tests DiscountService           # Запустит все тесты DiscountService*
./tests Billing                   # Запустит все тесты содержащие "Billing"
```

## Тестирование

Проект включает **55 тестов**, покрывающих:

- Создание и управление сущностями
- Проверка бизнес-логики
- Обработка ошибок
- Симуляция сбоев

### Интеграционные тесты Saga
- Успешное выполнение заказа
- Компенсация при недостатке средств
- Компенсация при недостатке товара
- Компенсация при сбое сервисов
- Отмена подтверждённого заказа с возвратом начального баланса
- Проверка конкретных уведомлений и их типов
- Проверка согласованности данных
- Тесты точности финансовых операций

## Демонстрация

Консольное приложение предоставляет интерактивное меню:

1. **Показать пользователей** - список пользователей с балансами и скидками
2. **Показать товары** - каталог товаров с ценами и остатками
3. **Показать заказы** - история заказов со статусами
4. **Создать заказ** - интерактивное создание заказа
5. **Отменить заказ** - отмена с компенсацией
6. **Показать уведомления** - лог уведомлений
7. **Показать логи** - детальные логи операций
8. **Симуляция сбоев** - включение/выключение сбоев сервисов
9. **Запустить демонстрацию** - автоматическая демонстрация сценариев
